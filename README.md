# A股四日形态在线选股系统

## 部署为无需安装 Python 的在线网页
1. 登录 GitHub，新建仓库（建议先使用私有仓库；Streamlit 社区云部署的仓库可见性支持情况以平台为准），上传本文件夹内**全部文件**，包括 `.github/workflows` 和 `.streamlit`。
2. 登录 Streamlit Community Cloud，点击 Create app / Deploy，选择该 GitHub 仓库、主分支，入口文件填 `app.py`，部署后平台会给出网址。
3. 在 GitHub 仓库 Actions 页面启用工作流 `A-share after-close scan`，可以点 Run workflow 手动运行首次扫描。计划时间为周一至周五北京时间 15:40；法定休市日不会自动跳过，可能保存上一交易日数据。GitHub 计划任务可能延迟或被跳过，扫描亦可能因免费行情接口限流失败。
4. 每次工作流提交 `scan_results.csv` 后，网页将展示最近一次保存的筛选结果；如平台未自动刷新部署，需在页面重新加载。

## 注意
- 当前是**可部署代码包，不是已上线网址**。需要在自己的 GitHub / Streamlit 账户部署。
- 网页支持手动扫描，耗时较长且可能被云端服务超时中断；建议主要查看每日自动任务保存的结果。
- 该形态只识别第三日收盘后的候选，**第四日开盘确认尚未自动实现**。
- 涨停判定为近似阈值；未严格校验上市满60日、停牌状态、精确涨停价及A股节假日。
- 没有配置回测模块或实时市场指数，不能把这些功能当作已实现。
- 公开部署且无登录意味着知道网址的人可能访问结果。
- 严格筛选可能无命中；免费行情源可能不可用。工作流失败时应查看 Actions 日志。
